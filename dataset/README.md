# Dataset

This project uses the **Fake and Real News Dataset** from Kaggle.

## Download

https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

## After downloading

Extract the archive and place the files inside the `dataset` folder.

```
dataset/
├── Fake.csv
└── True.csv
```

These files are not included in this repository because of GitHub file size limits.
